# Complete frontend ClojureScript lint gate

The advertised `pnpm -C frontend lint` command now reports **zero errors and
zero warnings** across production ClojureScript, development JVM helpers,
browser-test sources, every ClojureScript test and the shared source tree.
The optional linters, warning fail level, function/file limits and migration
ratchets remain enabled with their original thresholds.

Events now separates its native role/selected-job context from the existing
chat and audit bridge composition. Three rendered/projection regressions cover
restricted capability display, selected-job details, catalog feedback and the
unchanged bounded chat-pin contract. The existing bridge remains the tool
transport boundary, preserving its configured base URL and identity behavior.

Migration filesystem discovery now owns a dedicated Node adapter, and pure
path-containment obligations have their own law namespace. Existing public
entry points remain compatibility aliases. Containment, symlink refusal,
canonical manifests, route ownership and source-count non-regression are
unchanged and remain covered by the complete migration suite.

The advertised full test command passes **521 tests / 2,270 assertions**, zero
failures/errors, **289 files / zero compiler warnings**. The shared fatal-error
preload and summary validator are active. The isolated AVA browser-runner target
also compiles: **46 files / zero compiler warnings**. That compilation alone
does not claim its browser scenarios executed.

The development proxy adapter now names Shadow 3.4.11's actual
`shadow.http.server.HttpRequest` type with reflection warnings enabled. Its old
documentation named Undertow; trying that type failed with
`ClassNotFoundException`, because Undertow is no longer on this classpath.
Inspection of the installed Shadow server source and its Java request class
identified the current boundary. Six real request objects verify backend API,
WebSocket and health forwarding (including a query string), devtools exclusions
and the local application root. No replacement server or dependency was needed.

The complete production build also passes: Vite bridges and entry point,
Shadow advanced compilation (**176 files / zero warnings**) and Tailwind CSS.
The emitted app is frozen for the next real-stack browser tour. Browser AVA
compilation above remains distinct from that tour's execution evidence.

Run lint from the frontend workspace, or through its advertised parent routing:
its local clj-kondo configuration loads the Helix macro hooks. An invocation
from the repository root without that configuration produces false unresolved
component reports. The command routing now avoids that ambiguity.

The separate repository file-size gate still reports oversized inherited
TypeScript/TSX and backend files. It is not waived by this ClojureScript result,
and its thresholds and selected files have not been weakened.
